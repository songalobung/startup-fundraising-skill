# Security and privacy

This repository contains Markdown instructions and reference links. It does not include executable scripts or collect user data.

## Protect confidential information

Public GitHub issues and pull requests are visible to others. Do not upload pitch decks, financial models, cap tables, investor correspondence, customer records, credentials, or other non-public company information. Use synthetic examples when reporting a problem.

If you identify a security issue involving this repository or its distribution, use GitHub's private vulnerability reporting for this repository if available. If that option is unavailable, contact the repository owner through their GitHub profile without including sensitive information in a public issue.
